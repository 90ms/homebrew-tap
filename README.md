# 90ms Homebrew Tap

Homebrew packages maintained by [90ms](https://github.com/90ms).

## Agents Status Bar

A macOS menu-bar app for monitoring AI coding-agent quotas and token activity.

```bash
brew install --cask 90ms/tap/agents-status-bar
open -a "Agents Status Bar"
```

Project: [90ms/agents-status-bar](https://github.com/90ms/agents-status-bar)

## PR Review Reminder

A macOS menu-bar app for collecting GitHub review requests and preparing
AI-assisted review drafts.

```bash
brew install 90ms/tap/pr-review-reminder
pr-review-reminder --install-app
pr-review-reminder
```

Project: [90ms/pr-review-reminder](https://github.com/90ms/pr-review-reminder)

## Update

```bash
brew update
brew upgrade
```

Fully qualified install commands trust only the selected Formula or Cask on
Homebrew versions that require explicit trust for non-official taps.
